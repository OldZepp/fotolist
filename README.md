# ФотоЛист — сервис онлайн-заказа фотопечати

**ФотоЛист** — демонстрационная версия веб-сервиса фотопечати с интерактивным калькулятором стоимости и оформлением заказов онлайн.

Проект показывает, как можно автоматизировать прием заказов в фотосалоне: посетитель самостоятельно выбирает параметры печати, сразу видит итоговую стоимость, указывает пункт выдачи и отправляет заявку без участия менеджера.

### Демо сайта

**[Открыть ФотоЛист](https://oldzepp.github.io/fotolist/)**

### Возможности

- **Интерактивный калькулятор** — расчет стоимости в реальном времени.
- **Четыре формата фотографий** — 10×15, 13×18, 15×21 и 20×30 см.
- **Выбор фотобумаги** — глянцевая или матовая.
- **Срочная печать** — расчет дополнительной наценки.
- **Автоматическая скидка** — 10% при заказе от 50 фотографий.
- **Три пункта выдачи** — выбор удобного адреса.
- **Онлайн-оформление** — передача контактных данных и параметров заказа в Яндекс Формы.
- **Передача фотографий** — через ссылку на папку Яндекс Диска.
- **Проверка полей** — контроль обязательных данных, телефона и электронной почты.
- **Страница подтверждения** — переход после отправки заявки.
- **Адаптивный дизайн** — для компьютеров, планшетов и смартфонов.

### Дизайн и взаимодействие

Сайт оформлен в светлой природной палитре с зелеными акцентами. Визуальная концепция построена вокруг идеи сохранения воспоминаний.

Реализованы плавное появление элементов при прокрутке, анимированные фотокарточки, интерактивные кнопки и подсветка расчета стоимости.

Фотографии открываются в увеличенном виде с возможностью переключения между снимками. На мобильных устройствах поддерживается перелистывание свайпом.

### Как работает заказ

1. Посетитель выбирает формат, количество фотографий, бумагу и срок печати.
2. Калькулятор автоматически рассчитывает стоимость с учетом наценок и скидок.
3. Посетитель вводит контактные данные, выбирает пункт выдачи и добавляет ссылку на фотографии.
4. После проверки данных открывается Яндекс Форма с предзаполненными параметрами заказа.
5. Посетитель подтверждает отправку, а заявка сохраняется в Яндекс Формах.
6. После отправки доступен переход на страницу подтверждения заказа.

### Локальный запуск

Скачайте репозиторий и откройте `index.html` в браузере.

Для работы интерфейса не требуется установка дополнительных зависимостей.
